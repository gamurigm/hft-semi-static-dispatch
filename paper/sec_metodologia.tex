\section{Materials and Methods}

\subsection{Experimental Design}
We designed a statistical validation protocol based on Monte Carlo simulations with $K = 100$ independent trials, each utilizing a unique pseudorandom seed generated via \texttt{std::random\_device}. Each trial processed $N = 5 \times 10^6$ conditional dispatch operations, totaling $5 \times 10^8$ experimental observations.

Four dispatch strategies were evaluated:
\begin{itemize}
    \item \textbf{Native \texttt{switch}:} Conditional evaluation at each iteration (baseline).
    \item \textbf{\texttt{FastBranch}:} Experimental proposal with raw function pointers and infrequent updates ($f_{\text{set}} = 1/1000$).
    \item \textbf{\texttt{FlexBranch}:} Variant with \texttt{std::function} to quantify abstraction overhead.
    \item \textbf{Direct control:} Branchless call without conditional dispatch (theoretical limit).
\end{itemize}

The differences were validated through a non-parametric bootstrap resampling statistical analysis with $B = 10\,000$ iterations. This approach allows the construction of empirical 95\% confidence intervals (CIs), mitigating parametric normality assumptions that are typically violated in hardware latency measurements due to OS interrupts. Additionally, the effect size is reported using Cohen's $d$.

\subsection{Implementation and Architecture}
The \texttt{semi\_static.hpp} library was developed (header-only, C++17) with four variants (Table~\ref{tab:clases}). The core architecture is based on the physical decoupling between condition evaluation (\textit{cold path}) and dispatch execution (\textit{hot path}), as illustrated in Fig.~\ref{fig:arquitectura}.

\subsection{Execution Environment}
Tests were executed on a Linux environment (Ubuntu 24.04 LTS), powered by an Intel processor with 12 logical cores, compiled with GCC~13.3 (\texttt{-O2}, C++17). Temporal instrumentation was performed via \texttt{std::chrono::high\_resolution\_clock}. The random conditions were pre-generated before each trial to ensure that the overhead of the pseudorandom number generator (RNG) did not pollute the hot-path latency measurements.
